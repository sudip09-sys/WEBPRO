# WebPRO

Learn. Build. Repeat.

A personal web programming learning hub by **Sudip Sah** · [@sudip09-sys](https://github.com/sudip09-sys).

- 13 lectures with readable notes, slides and module downloads
- JavaScript, TypeScript and Angular learning paths
- Interactive memory games, piano, quiz and browser-local messenger examples
- Scrambling headlines, responsive layout and locally saved progress
- No installation needed to use the published site

## Local preview

Serve this directory with any static HTTP server. Open `index.html`. Opening files directly can prevent JSON loading and browser storage features.

## Working examples and assignment files

Each lecture links to a working browser example and its original educational starter files. The examples demonstrate behavior; they are not a claim that every implementation constraint or grading rubric is satisfied. In particular, the browser-local messenger uses localStorage and BroadcastChannel, not Angular or the private course API. The original TypeScript and Angular projects remain included for study and development. Course backend/VPN behavior has not been tested.

The local messenger is a learning demo, not production authentication. Use demo passwords only. Its guide contact is explicitly simulated. Two registered accounts in separate tabs can exchange messages locally.

## Deployment

GitHub Pages uses the **Publish WebPRO** workflow. The workflow includes the authorized educational materials and verifies JavaScript syntax before publishing.
