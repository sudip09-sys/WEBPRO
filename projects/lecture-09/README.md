# WebPRO / Lecture 9

Conversations with a little character.

Maintained by **Sudip Sah** (@sudip09-sys).

## Run
Serve this folder with a static HTTP server and open index.html. A compiled version is included.

## Source
TypeScript source is in src/. Run npm install then npm run build to regenerate build/.

The messenger runs with local demo accounts by default. Use demo passwords only. For the live course service, configure the backend URL and connect to its VPN. Live backend behavior has not been verified. Do not use this educational demo as production authentication.
